# DSH Session Library · 会话库

> 个人自用插件，代码和文档由 AI 参与编写，不承诺维护。使用前请先备份 DSH 配置。

给 DeepSeek Harness 大量历史会话使用的独立插件。左侧只渲染最近少量会话，全部记录放在按需打开、分页渲染的会话库中。

## 功能

- 侧栏提供“活跃 / 非活跃 / 全部”三个图标视图，默认最多显示 30 行。各视图都按真实分区显示；活跃区不超过 12 条时停止超时降级，已在非活跃区的会话不会因活跃区不足而自动回来。会话右键菜单的“设为不活跃”可手动移到非活跃区顶部；活跃区会话行上还有一个悬停即现的月牙快捷按钮（平时不透明度可在显示设置里调，默认 30%）。显示设置里还有“会话行紧凑度”滑杆。缓存阶段点击会话会等实时列表就绪后再自动打开。
- 新建会话、从当前活跃区之外重新启用的会话进入顶部；已经在活跃区的会话发消息仍在原位，刷新后也保留顺序。普通阅读、绿点清除和状态变化不重排行序。置顶行固定在两区上方。右侧分组图标切换平铺与项目分组。
- 活跃/非活跃分区的顺序和最近活动时间会同步到服务器（`<dshHome>/storages/session-library-sections.json`，最后写入者为准）：在一个浏览器设为不活跃，其他浏览器在聚焦或最多 20 秒内跟随，不会再回到活跃区。浏览器各自的超时降级规则不变；服务器不可用时退回本地 localStorage。
- 浏览器保存一份轻量活跃区缓存：后续打开页面先显示缓存，后台加载完整列表后完全以实时数据为准。缓存只保存标题、路径及分组等元数据，不保存正文或瞬态状态；最多 100 条、256 KiB、7 天，存储不可用时照常加载。
- 冷会话标题直接取已有列表响应中的标题投影，避免暂时退回显示工作目录名；侧栏、搜索、会话库和启动缓存共用同一标题解析，不额外拉取会话日志。
- 侧边栏内搜索会话名称即时过滤；“新会话”按分组继承工作区；“添加工作区…”使用网页目录浏览器，不依赖服务器桌面能力。
- 按钮名称及会话路径在悬停 0.6 秒后提示，按钮右键立即显示名称；会话行右键仍打开原操作菜单。项目组头菜单提供工作区操作。
- “全部会话”入口：全部 / 未归档 / 已归档 / 回收站；标题、会话 ID、目录与工作区检索，工作区筛选和排序；列表 / 文件夹两种视图随时切换，行内显示工作目录路径；文件夹视图按“文件夹 → 工作区 → 未分组”分组，与官方侧栏语义一致。
- 每页 25、50 或 100 条；关闭管理页即卸载其列表。
- 正文搜索使用宿主的公开查询 API；“已归档”范围使用归档专用检索，避免其他匹配先挤满结果。
- 只读文字预览，可查看归档记录而不取消归档；普通会话可直接打开继续聊天。
- 会话重命名沿用官方语义：改过的标题会被钉住，不再被自动标题覆盖。
- 归档对运行中的会话也可点击：先弹出官方确认框，列出将被停止的回合、子智能体、后台任务与定时提醒，确认后停止并归档，取消则一切照旧。
- 置顶、归档和恢复归档使用官方公共 API。运行中会话不会被自动停止。
- 删除改为“移到回收站”：保留会话与投影缓存副本，支持恢复；拒绝正在加载、运行、被占用、旧格式和身份不一致的会话（运行中会话请先归档停止）。
- 侧边栏和每页条数可在会话库的“显示设置”，或 DSH 设置中的“会话库”调整，保存于当前浏览器。
- 会话行状态用彩色圆点标示：蓝色呼吸＝运行中、橙色＝需要你处理（审批/计划评审/提问）、绿色＝有新回复、红色＝出错（依赖宿主的 api-session/error 事件，回合内部失败不广播则不标）。
- 绿色“有新回复”由服务器记录（`<dshHome>/storages/session-library-unread.json`）：宿主在每回合结束时打标，任何浏览器打开页面都会亮，重启不丢；任何一端打开该会话就把标记清掉，其余端在聚焦或最多 10 秒内跟随。只有单个客户端在本地观察到的旧实现会漏掉“关着页面时完成的回合”，0.2.15 起不再如此。
- “会话区高度”按侧栏总高的百分比（20%–90%）自由调整：低于自然高度时收窄会话区，高于时压缩“全局面板”列表（变为可滚动）；自适应即不干预。
- 启动时会把重复的会话列表请求合并：宿主的启动序列会拉两次全量 `session/list`（侧栏懒装载 baseline + 连接层首个 generation 的刷新），插件在传输出口对 3 秒内在途的请求做合并并按调用方重盖章 rpcId，每次加载少传约 7MB。
- **历史库（history vault）**：把长期不活跃的会话整体移出 `sessions/`，存入 `<dshHome>/history-vault/`，让侧栏和会话列表只加载最近会话。“全部”视图会合并显示历史库会话（带“历史库”标记和“恢复”按钮）；会话右键菜单也能“移入历史库”。恢复会把会话、投影缓存和置顶/归档状态完整搬回原位，对话可以继续。迁移判据按记录的最后发言时间（projcache lastPromptAt）而不是文件修改时间，避免批量导入摸新 mtime 导致旧会话永远留下来；正在运行或加载中的会话一律跳过。全程只做目录级 rename 和校验，恢复前后都有哈希与身份检查，索引 `index.json` 原子写入。
- **会话模型工具（0.3 起同时覆盖活跃会话与历史库）**：host 侧向 dsh 注册三个模型工具，任何 dsh 会话里的 agent 都可以直接使用——`session_search`（一次搜索活跃会话和历文库，按标题/id/cwd 关键词匹配，命中带 `live` / `vault` 标记和最后活动时间）、`session_read`（按 id 读取消息内容，自动判断在活跃列表还是历史库，可分段翻页）、`session_restore`（把历史库会话搬回 dsh 继续对话）。活跃会话的标题取投影缓存，不额外打开日志；子代理会话不进结果。恢复是唯一的写操作，其余只读。工具随插件自动注册，并在系统提示里附带使用说明。

## 与 Chat Manager 的关系

本插件独立运行，不依赖 `dsh-chat-manager`。包含其归档内容检索与清理用途，并提供全部会话浏览和轻量侧边栏。后端部分沿用其 MIT 授权的请求验证与查询设计，见 THIRD_PARTY_NOTICES.md。

建议使用本插件时停用 Chat Manager，避免同时出现旧的永久删除入口。卸载或停用本插件不删除任何会话；原版侧边栏会恢复。

## 安装

支持基线：DeepSeek Harness `0.2.2-rc.1`，Node.js `>=24.9.0`。

开发安装：

```sh
npm install --ignore-scripts
npm run check
```

在 DSH 插件管理界面添加本项目的绝对目录，例如：

```text
link:/absolute/path/to/dsh-session-library
```

也可用 `npm pack` 生成可安装包。请使用官方插件管理生命周期启用或停用 bundle。

修改源码后执行 `npm run build` 更新客户端产物，再通过 DSH 生命周期重载插件并刷新网页。发行包已包含构建后的客户端，不要求用户安装前端构建工具。

## 回收站与恢复

回收站保存在当前 DSH home 下的 `archive/session-library-trash/`，每项包含原始记录、可用的投影缓存以及恢复清单。不会自动清空，不提供永久删除入口。

恢复会拒绝覆盖相同 ID、文件或缓存。原始回收站备份在恢复后仍保留，已恢复项不再列入可恢复列表。旧版本日志保留在备份内，恢复仅发布当前有效日志，避免错误选中旧代记录。需要支持本地硬链接的文件系统；跨设备或存储异常会明确报告，并保留恢复副本。

如果归档/置顶标记更新失败，会报告部分成功。若文件移动或恢复未完成，不自动销毁现场；保留备份供检查。外部附件、其他应用的副本不在清理范围内。

## 性能边界

本插件减少浏览器 DOM 和样式计算负担，不修改 DSH 日志格式、服务器全量列表扫描或列表 API。首次列表请求仍可能较慢。大量置顶/待处理会话会使侧边栏超过设置数量，以免隐藏需要关注的会话。

正文搜索受宿主结果上限约束，达到上限时会提示缩小关键词；不伪装成完整搜索结果。预览只输出有限数量、有限长度的用户与助手文字，不渲染任意 HTML 或自动加载外部资源。完整记录仍在原会话中。
